# Lingmo OS User Experience Program License Agreement

Effective date: to be filled in

## 1. About

The User Experience Program (the "Program") is an **optional** feature of
Lingmo OS. It helps us understand how the system behaves on real hardware so we
can fix defects and improve performance and usability.

**The Program is off by default.** It only takes effect after you switch it on
under Control Centre - System Information, and you can switch it off at any
time, which stops collection immediately.

## 2. What is collected once you opt in

With your explicit consent the Program collects **anonymous or de-identified**
information such as:

- system version, build number and desktop environment version;
- hardware outline: CPU architecture and core count, memory size range, GPU
  class, screen resolution range;
- aggregated counts of component failures and crashes (never the file contents
  involved in a crash);
- aggregated usage counters (for example how often a settings page was opened);
- whether certain optional components are enabled.

Everything collected is aggregate statistics used to assess stability and usage
trends.

## 3. What is never collected

The Program does **not** collect:

- the contents, names or directory structure of your files;
- keystrokes, clipboard contents or screenshots;
- browsing history, chat contents, accounts or passwords;
- precise location;
- anything that directly identifies you (name, phone number, e-mail address,
  device serial number and so on).

## 4. How the data is used and kept

Collected data is used only to:

- measure the rate of crashes and failures in order to find and fix defects;
- assess hardware compatibility and performance problems;
- understand which features are used, in order to prioritise improvements.

Data is kept in aggregate form. It is not used for advertising and is not sold
or handed to third parties for marketing.

## 5. Your choices

- Enable or disable: Control Centre - System Information - User Experience
  Program;
- once disabled, no further data is sent;
- after disabling, you may contact us to request deletion of records previously
  submitted by your device.

## 6. Miscellaneous

The Program does not affect normal operation of the system. Declining to take
part restricts no functionality.
