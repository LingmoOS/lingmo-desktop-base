# Lingmo OS 用户体验改善计划许可协议

生效日期：待填写

## 一、说明

"用户体验改善计划"（以下称"本计划"）是 Lingmo OS 提供的**可选**功能，
用于帮助我们了解系统在真实硬件上的运行情况，从而定位缺陷、改进性能与体验。

**本计划默认关闭。** 只有你在"控制中心 → 系统信息"中主动打开后才会生效；
你也可以随时关闭，关闭后立即停止收集。

## 二、参与后收集的内容

在你明确同意后，本计划会收集以下**匿名或去标识化**的信息：

- 系统版本、构建号、桌面环境版本；
- 硬件概况：CPU 架构与核心数、内存容量区间、显卡型号类别、屏幕分辨率区间；
- 组件异常与崩溃记录的统计信息（不含崩溃时的文件内容）；
- 功能的调用次数等汇总统计（例如某设置页被打开的次数）；
- 是否启用某些可选组件。

收集内容均为**汇总统计**，用于评估稳定性与使用趋势。

## 三、明确不收集的内容

本计划**不会**收集：

- 你的文件内容、文件名或目录结构；
- 键盘输入、剪贴板内容、屏幕截图；
- 浏览记录、聊天内容、账号与密码；
- 精确地理位置；
- 任何可用于直接识别你个人身份的信息（姓名、手机号、邮箱、设备序列号等）。

## 四、数据的使用与保存

收集到的数据仅用于：

- 统计崩溃与异常的发生率，定位并修复缺陷；
- 评估硬件兼容性与性能问题；
- 了解功能使用情况，以决定改进优先级。

数据以汇总形式保存，不用于广告投放，也不会出售或提供给第三方用于营销。

## 五、你的选择

- 打开/关闭：控制中心 → 系统信息 → 用户体验改善计划；
- 关闭后不再发送任何数据；
- 你可以在关闭后联系我们，要求删除此前由你的设备提交的记录。

## 六、其他

本计划不影响系统的正常功能。不参与本计划不会导致任何功能受限。
